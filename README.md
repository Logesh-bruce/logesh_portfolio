## Getting Started

### Prerequisites

- Node.js (if applicable)
- npm or yarn

### Installation

```bash
git clone https://github.com/Logesh-bruce/logesh_portfolio.git
cd logesh_portfolio
npm install
```

### Running Locally

```bash
npm start
```

Then open `http://localhost:3000` (or your dev server's port) in your browser.

### Building for Production

```bash
npm run build
```
